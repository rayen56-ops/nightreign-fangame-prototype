ACCEPTANCE_CRITERIA:

A project launches successfully in Godot
A procedural dungeon remains playable
A player occupies exactly one 16x16 logical tile
A player is visually represented by a 32x32 frame
A player supports 8-direction grid movement
A move advances one game turn regardless of animation
A viewport remains 576x324 logical
A standard desktop mode displays at 1152x648
A pet-size mode displays at 576x324
A gameplay framing remains 16:9
A pixel art remains crisp with no texture smoothing
A changing window profile does not alter gameplay rules
A existing core roguelike systems remain operational

PRIORITY:
architecture_stability > pixel_consistency > compatibility_with_existing_code > visual_polish > new_features

Before making destructive architecture changes, inspect the existing implementation and adapt to it. Do not replace functioning Statico systems merely to conform to this specification if the same behavior can be obtained with a smaller modification.
