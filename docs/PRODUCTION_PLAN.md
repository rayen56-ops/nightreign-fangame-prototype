# 黑夜地城：製作總綱（2026-09-16）

## 最終成品

一款 Windows 單人、八方向、格子回合制的《黑夜君臨》同人遊戲。參考《ディアボロの大冒険》與不可思議地牢的探索、資源取捨及道具互動。每個成功行動後敵人各有一次行動機會；思考、選單、取消與非法操作不推進時間。

忠實保留原作的辨識核心：渡夜者的被動／小招／大招，武器類型與能力補正，敵人的代表性攻擊、夜王的預兆與階段、冷色廢墟與黃金／火焰光源。所有秒數、範圍與動作反應轉成明確的回合、格數與預告區域。適應回合制的數值是本作設計，不能宣稱與原作完全一致。

## 設計決策

- 角色能力：生命、精神、耐力、力量、靈巧、智力、信仰、感應，對玩家顯示 S/A/B/C/D/E。HP、技能冷卻與大招蓄積仍用可讀的數字。
- 武器沒有能力門檻；能力補正決定適配程度。內部 grade 分數 E=1…S=6；首版傷害公式為基礎傷害 + 各能力分數×該補正係數，明示於資料和 UI。
- 攻击採確定傷害，讀招與站位提供主要風險；首版取消原型 d20 命中落空。
- 小招使用回合冷卻，大招使用戰鬥蓄積；不靠原地等待充滿大招。
- 地城一局分成探索區、深層區與夜王領域。首段 3 層；後續擴為三晝夜路線、地形變動和多夜王遠征。
- 每層一次賜福補給；拾取武器／道具可改變打法；不要塞入範例中的現代軍事裝備和食物。
- 美術不再受 32×32 硬限制；新人物目標 48～64px 工作畫格，Boss 96～128px，依真正遊戲視角決定顯示大小。視覺尺寸永不改變佔格。參考圖定義外形和氣氛；不以縮小插畫冒充完成的像素美術。
- 保留底層地圖、FOV、Action、背包／装備架構，以角色／武器資料與遠征規則層接入。

## 製作順序與完成門檻

### M1：第一段完整可玩遠征（本輪製作）

Wylder／復仇者，小招＋大招、S～E 能力／武器補正、數種原作致敬武器與補給、原型敵群、3 層路線、Gladius 原型預兆戰、通關／死亡／重開。驗證有效行動 1:1 回合，失敗行動零消耗、技能冷卻、大招、召喚、武器無門檻、樓層與勝負。M1 美術品質及敵人動作仍須明確列出未完成項目。

### M2：美術與手感定稿

Wylder／復仇者原生像素重設計、可讀的地形與門／階梯／賜福、三種敵人的正式剪影、Gladius 火焰與鎖鏈形象；中文 UI、方向提示、控制器與明確命中效果。兩位角色八方向 idle/move/attack/hit；先驗證角色與地形真實顯示，再量產。

### M3：完整成長與道具互動

武器系列／稀有度／升級、屬性與異常累積、道具投擲、符文與成長、商人、寶箱、陷阱、賜福、存檔／恢復／種子重現；所有核心互動自動化測試。

### M4：擴充原作角色與夜王

首批以本篇 8 位渡夜者與 8 位夜王為內容目標，逐個先查核來源、寫回合制規則，再做驗收後加入。DLC 角色與夜王列在擴充清單。每個 Boss 至少 3 招、2 階段、可讀預兆、明確弱點及一個代表原作的獨特機制。

### M5：可發布版本

完整一局存檔／恢復、教學、設定、音效／音樂、效能、重開記憶體、可攜執行包及版本回歸。以可玩與可辨識度驗收，不以清單數量或產圖張數當完成。
