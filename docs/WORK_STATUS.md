# Nightreign fan-game prototype status

The repository has been materialized into a complete Godot project. The current development target is the M1.1 vertical slice: turn-for-turn dungeon combat, S–E character scaling, data-driven weapons without hard requirements, Night Tide pressure, Wylder skill/ultimate flow, consumable expedition items, and a Gladius-style Nightlord encounter.

The next commit applies the locally validated source patch from the uploaded NightreignGrid project; runtime/Godot.exe and editor caches remain intentionally excluded from source control.
